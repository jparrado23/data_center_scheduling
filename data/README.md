# Data

This project currently uses synthetic data generated by `src/data/synthetic.py`.

Future processed inputs should use:

- `data/processed/jobs.csv`
- `data/processed/hourly_inputs.csv`
- `data/processed/clusters.json`
- `data/processed/config.json`

Expected `jobs.csv` schema:

```text
job_id,category,duration,power,earliest_start,latest_start
```

Expected `hourly_inputs.csv` schema:

```text
hour,renewable_available,grid_price
```

Expected `clusters.json` schema:

```json
[
  {
    "cluster_id": "gpu_a100",
    "capacity": 32,
    "compatible_categories": ["training", "inference"]
  }
]
```

Expected `config.json` schema:

```json
{
  "contracted_power": 70,
  "renewable_price": 50,
  "peak_price": 1000,
  "delta_t": 1
}
```
